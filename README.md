# ICT-4370-Spring2025-FinalPortfolio

A Python investment-analysis coursework project demonstrating object-oriented programming, file I/O, SQLite storage, CSV reporting, command-line filtering, and Matplotlib visualization.

## Privacy-safe sample data
The committed input files use fictional symbols and sample values. The default report identity is a demo investor with a reserved placeholder phone number and sample location. Do not put personal contact details, real account holdings, or private financial information in this repository.

## Run
Install Matplotlib, then run `python final_portfolio_project.py`. The script reads the adjacent sample input files and creates a local SQLite database, a text report, a CSV summary, and a chart. Generated outputs should be reviewed before committing.

## Scope
This is an academic demonstration, not investment advice or a production financial application. Annualized return is a simplified coursework calculation and is not a complete investment-performance measure.
